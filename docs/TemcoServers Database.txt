	Data Flow When a Bank Slip is Uploaded
1. Student uploads slip
2. Create VOUCHER (invoice header)
  → vid, id=auto (e.g., "SSP000001"), date, voucher_total,
    general_user_profilegup_id, voucher_typevt_id=1 (SSP),
    user_loginlogin_id, is_completed=0 (pending verification)
 
3. Create VOUCHER_ITEM (receipt line — DEBIT bank)
  → description="Bank Transfer", amount,
    sub_chart_of_accountis_sca → Bank sub-account,
    bank_reference_no=student's reference,
    vouchervid → parent voucher
 
4. Create VOUCHER_ITEM (receipt line — CREDIT revenue)
  → description="Starter Plan Subscription", amount,
    sub_chart_of_accountis_sca → Plan Revenue sub-account,
    vouchervid → parent voucher
 
5. Admin verifies slip → set voucher.is_completed=1
For the bank slip file URL
The voucher_item table already has bank_reference_no. I suggest adding a column slip_url VARCHAR(500) to voucher_item to store the uploaded file path. Alternatively, we can store it on the voucher table if you prefer one slip per invoice.

1. account_type — seed 5 types (Assets, Liabilities, Equity, Revenue, Expenses)
2. main_chart_of_account — seed main groups
3. chart_of_account — seed bank accounts + revenue/expense accounts
4. sub_chart_of_account — seed plan-level sub-accounts (unary tree)
5. payment_mode — seed "Bank Transfer"
6. voucher — new row per payment (invoice header)
7. voucher_item — 2 rows per payment (debit bank, credit revenue) + slip_url
